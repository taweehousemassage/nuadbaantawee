# Rich Menu เมนูล่างแชท — LINE OA พี่หนึ่ง

เมนู 4 ปุ่มติดก้นแชทตลอดเวลา — เลย์เอาต์ **2×2 บนเมนูใหญ่ 2500×1686** (ตรงกับเทมเพลตสำเร็จ "4 ช่อง" ของ LINE OA Manager กดเลือกได้เลย):

```
┌─────────────┬─────────────┐
│  จองนวด     │ นัด/คิวของฉัน │
├─────────────┼─────────────┤
│ แจ้งโอน·สลิป │ ทักหาพี่หนึ่ง │
└─────────────┴─────────────┘
```

| ปุ่ม | กดแล้ว |
|---|---|
| 📅 จองนวด (ซ้ายบน) | เปิดหน้าเว็บจอง `/` |
| 🎫 นัด/คิวของฉัน (ขวาบน) | บอทบอกวิธีเช็กนัด (พิมพ์ `นัดนวด <รหัส>` / `บัตรคิวนวด <เลข>`) |
| 🧾 แจ้งโอน·สลิป (ซ้ายล่าง) | บอทบอกให้ส่งรูปสลิปในแชท |
| 💬 ทักหาพี่หนึ่ง (ขวาล่าง) | บอทตอบเวลาทำการ แล้วพี่หนึ่งมาตอบต่อ |

ปุ่มที่ 2–4 ตอบอัตโนมัติผ่าน webhook `/api/line/webhook` (โค้ดอยู่ใน `routes.js` แล้ว — ไม่นับโควตา push)

## ติดตั้ง (เลือก 1 วิธี — ทำหลังมี LINE OA + token แล้ว)

**วิธี A — สคริปต์ (เร็วสุด)**
```bash
NUAD_LINE_CHANNEL_ACCESS_TOKEN=<โทเคนของ OA พี่หนึ่ง> bash setup-richmenu.sh
```
สคริปต์จะสร้างเมนู อัปโหลด `richmenu.png` และตั้งเป็นเมนูเริ่มต้นให้เอง

**วิธี B — ผ่านหน้าเว็บ LINE OA Manager (ไม่ต้องใช้โค้ด)**
1. https://manager.line.biz → เลือก OA พี่หนึ่ง → หน้าหลัก → Rich menu → สร้างใหม่
2. Template → เลือกแบบ **4 ช่องสี่เหลี่ยม (2×2) ของเมนูใหญ่** → อัปโหลดรูป `richmenu.png`
3. ตั้ง action แต่ละช่อง:
   - ซ้ายบน = Link `https://<ชื่อเว็บใหม่>.onrender.com`
   - ขวาบน = ข้อความ `ดูนัดของฉัน`
   - ซ้ายล่าง = ข้อความ `แจ้งโอน`
   - ขวาล่าง = ข้อความ `สอบถาม`
4. เปิดใช้งาน (Display)

## แก้ไขภายหลัง
- อยากเปลี่ยนคำ/ปุ่ม: แก้ `richmenu.json` แล้วรันสคริปต์ใหม่ (ลบเมนูเก่าก่อนถ้าต้องการ)
- อยากเปลี่ยนดีไซน์รูป: รูปต้องขนาด 2500×843 px (.png/.jpg)
