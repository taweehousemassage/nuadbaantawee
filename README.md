# นวดเส้นบ้านทวี — เว็บจองคิว

Node/Express + MongoDB + LINE OA · เว็บของตัวเอง ไม่ผูกกับเว็บอื่น

| หน้า | ลิงก์ |
|---|---|
| ลูกค้า (โดม + นอกสถานที่) | `/` |
| รับบัตรคิวหน้าร้าน (ปุ่มมุมขวาบน / QR ติดหน้าร้าน) | `/?walk=1` |
| หน้าพี่หนึ่ง | `/admin` (รหัส `ADMIN_PASSWORD`) |
| LINE webhook | `/api/line/webhook` |
| ปลุกเว็บ (cron-job.org) | `/health` |

## 3 ช่องทางบนหน้าแรก
1. **คิวโดมผู้สูงอายุ** จ.–ศ. 9:00–12:00 · สล็อตละ 15 นาที · **ฟรี** จองแล้วมาเลย
2. **นวดนอกสถานที่** จ.–ศ. 13:00–17:00 · ลูกค้าปักหมุดแผนที่ + เลือกช่วงเวลากว้าง ๆ
   → ระบบวัดระยะทางถนนจริง (OSRM) คิดค่าเดินทาง**ตามมิเตอร์แท็กซี่ ไป-กลับ ×2** จาก "บ้านโนนขี้ตุ่น"
   → ส่งงานเข้าไลน์พี่หนึ่ง · พี่หนึ่งพิมพ์ `รับงาน <รหัส>` / `เจรจา <รหัส>` / `ไม่รับ <รหัส>` หรือกดปุ่มใน `/admin`
   → รับงานแล้วลูกค้าเห็นยอด = ค่าเดินทาง + ค่าครูขั้นต่ำ 100 (โอนมากกว่าได้) → โอน → ส่งสลิปในแชทไลน์
3. **บัตรคิวหน้าร้าน** ปุ่มมุมขวาบน (ใช้ตอนออกร้านที่ตลาดคุณปู่ ส.–อา.)

## สูตรค่าเดินทาง (แก้ค่าเริ่มต้นได้ในหน้าตั้งค่า)
มิเตอร์ไทย: เริ่ม 35 บาท (1 กม. แรก) · 1–10 กม. กม.ละ 6.50 · 10–20 กม. 7 · 20–40 กม. 8 · 40–60 กม. 8.50 · 60–80 กม. 9 · เกิน 80 กม. 10.50 — แล้ว ×2 (ไป-กลับ)
ถ้าเรียก OSRM ไม่ได้ ระบบใช้เส้นตรง ×1.35 แล้วติดป้ายว่า "ประมาณ" · พี่หนึ่งแก้ตัวเลข กม. ได้ก่อนกดรับงาน

## รันในเครื่อง
```bash
npm install
cp .env.example .env     # ใส่ ADMIN_PASSWORD
node server.js           # http://localhost:3000
```

## ขึ้นเว็บ (Render ฟรี)
1. GitHub repo ใหม่ → อัปทั้งโฟลเดอร์ (ยกเว้น `node_modules/`, `.env`, `data/`)
2. Render → New → Blueprint (มี `render.yaml`) → ใส่ Environment ตาม `.env.example`
3. cron-job.org ยิง `<เว็บ>/health` (Render ฟรี 750 ชม./เดือน/บัญชี — ถ้ามีหลายเว็บต้องแบ่งช่วงเวลา ping)
4. LINE Developers (OA `@923frfkh`) → Messaging API → Webhook URL = `<เว็บ>/api/line/webhook` → Verify → เปิด Use webhook
5. `/admin` → ตั้งค่า: พร้อมเพย์ · **พิกัดบ้านโนนขี้ตุ่น (วางลิงก์ Google Maps ได้เลย)** · เวลาโดม/นอกสถานที่ · ค่าครูขั้นต่ำ
6. ไลน์ส่วนตัวพี่หนึ่งทักแชท OA: `ผูกหมอนวด <OWNER_CODE>` → จากนั้นงานใหม่จะเด้งเข้าไลน์

## ตัวแปร
`ADMIN_PASSWORD` `OWNER_CODE` `MONGODB_URI` (`MONGODB_DB` `MONGODB_COLLECTION`) `PUBLIC_BASE_URL`
`LINE_CHANNEL_SECRET` `LINE_CHANNEL_ACCESS_TOKEN` `LINE_OA_ID` `LINE_ADD_FRIEND_URL` · รองรับชื่อเดิมขึ้นต้น `NUAD_` ด้วย

## โครงไฟล์
`server.js` เปิดเว็บ · `routes.js` API + webhook · `store.js` ข้อมูล · `logic.js` เวลา/คิว · `fare.js` ระยะทาง+มิเตอร์ · `line.js` ส่งไลน์
`public/` — `index.html` หน้าลูกค้า · `admin.html` หน้าพี่หนึ่ง · `messages.js` ถ้อยคำทุกข้อความ · `style.css` ธีมไทยโบราณ
